入门

这个应用是什么、第一个界面，以及如何找到各项功能。

Stock Management 是什么？

一款面向商店、仓库和小企业的库存管理应用。你可以维护带 SKU 和条码的产品清单，记录入库和出库，随时知道有多少货、在哪里、值多少钱。它还能做盘点、带打印单据的销售、报表、标签和备份。

所有数据都保存在你的手机上。无需注册账号，也没有订阅费用。

需要账号或网络吗？

不需要。应用可以完全离线使用，没有登录。除非你自己把数据发到别处（例如备份或导出的报表），数据不会离开设备。

只有少数功能会用到网络：发送反馈、打开 Google Play 页面、备份到 FTP 或 SMB 服务器，以及远程访问（它使用的是你的本地 Wi-Fi，而不是互联网）。

第一个界面问我想如何开始，该选哪个？
  • 恢复备份 — 你在另一部手机上用过本应用，并且有备份。请看换到新手机。
  • 从电子表格导入 — 你的产品已经在 Excel 或 Google 表格里。请看导入。
  • 从我自己的库存开始 — 空白应用，逐个添加产品。
  • 示例数据（综合商店、服装店、书店）— 用演示产品填满应用，方便你四处看看。

这个界面只出现一次，但选择不会让你失去什么：之后随时都可以导入、恢复或添加产品。

如何加载或移除示例数据？

只有在应用为空时才能添加示例数据：在欢迎界面，或者在仪表盘的 用示例数据试一试 卡片中。添加之前，应用会明确告诉你将添加多少产品、类别、供应商和位置。

要移除，点击仪表盘横幅上的 清除示例数据。只会删除示例记录。

所有界面在哪里？底部只有四个。

在手机上，底部栏显示仪表盘和菜单中的前三个界面。其余界面都在每个界面右上角的 ⋮ 菜单里：销售、盘点、交易、报表、分类、供应商、位置、标签、导入、备份、回收站、远程访问和设置。在平板上，它们都在侧边栏中。

要选择哪些界面放在底部栏，进入 设置 → 菜单配置，把它们上移或下移。从不使用的界面也可以隐藏（仪表盘和设置始终保留）。

如何更改语言？

设置 → 语言。应用支持 English、Español、Français、Português、Русский、中文、العربية、हिन्दी、বাংলা、اردو 和 Bahasa Indonesia。

仪表盘显示什么？

产品总数、低库存、库存价值、最近变动、提醒和图表（库存水平、按类别的产品数和价值、7 天和 30 天的变动、需要补货的产品、按位置和供应商的库存价值、变动最多的产品，以及即将过期的批次）。

点击仪表盘底部的 自定义仪表盘，或进入 设置 → 仪表盘，可以隐藏卡片、调整顺序并设置每张卡片的宽度。

产品

添加、编辑、整理和查找产品。

如何添加产品？
  1. 打开 产品，点击 +。
  2. 填写 SKU 和 名称（两者都是必填）。SKU 是你给商品的编码，不能重复。
  3. 可选：添加照片、描述、类别、位置、供应商、单位（个、千克、升……）、最低和最高库存、成本价、售价和条码。条码栏旁边有扫码按钮。
  4. 在 数量 中填写你现在的数量。它会被记录为该产品的初始库存。
  5. 点击 保存产品。

更快的方法：在扫描中扫描一个未知条码，然后点击 以此条码添加产品；或者从表格导入整个清单。

为什么编辑产品时不能修改数量？

这是有意设计的。每一次库存变化都会记录为一条变动（谁、何时、为什么、变动前后），这样记录始终对得上。请通过 入库 / 出库、快速库存、扫描 或盘点来修改数量。产品的其他信息（名称、价格、条码、类别……）用产品页上的铅笔图标编辑。

如何给产品添加照片？

在产品表单中点击 添加照片，然后选择 拍照 或 从相册选择。没有照片的产品会显示一个其类别颜色的包裹图案。

如何删除产品？还能找回吗？

打开产品，点击顶部的垃圾桶图标。它过去的变动仍保留在记录中。产品会进入回收站，以后可以从那里恢复。

如何搜索、排序和筛选产品列表？

搜索框可以按名称、SKU 或条码查找产品；旁边的扫码按钮可以通过扫码搜索。排序和筛选按钮可按名称、数量、库存价值或最近更新排序，并把列表限定为一个类别。在仪表盘上点击 低库存，会打开只显示低库存产品的列表。在平板上还可以选择列表显示几列。

可以选择列表中每个产品显示什么吗？

可以：设置 → 产品卡片 → 自定义产品卡片。可以显示或隐藏照片、类别、供应商、位置、价格、成本、描述、库存条等，并按你想要的顺序排列。实时预览会显示效果。

类别、供应商和位置是怎么用的？

它们是你给产品归类用的列表。在 ⋮ 菜单中各自的界面（分类、供应商、位置）用 + 创建，或者让导入自动创建。然后在产品表单中选择。

点击任意类别、供应商或位置，可以看到归在其下的产品以及每个产品的库存数量。

删除它们绝不会删除产品：产品只是不再属于该类别、供应商或位置；从回收站恢复后会重新关联。

“低库存”是怎么判断的？

每个产品都有自己的 最低库存。数量等于或低于它时，产品被标记为低库存（为零时标记为缺货）。如果设置了 最高库存 且超过它，则标记为库存过剩。

新产品默认填入的值在 设置 → 默认最低库存阈值 中设置。低库存产品会显示在仪表盘、产品列表（点击低库存卡片）、低库存报表以及每日低库存提醒中。

如何更改货币？

设置 → 常规 → 货币符号。输入你使用的符号（例如 ¥、HK$、NT$、$）。这只改变价格的显示方式，不会换算金额。

入库与出库

记录到货和出货。

如何增加或减少库存？
  1. 打开产品，点击 调整库存。
  2. 选择 入库（到货、退货）或 出库（销售、损坏、领用）。
  3. 输入数量，也可以写一个原因（“订单 123”“损坏”）。
  4. 如果你使用了位置，选择库存进入哪里或从哪里出。
  5. 确认。新数量会立即显示，这条变动会加入交易。

在产品列表、快速库存以及扫描扫码之后，打开的都是同一个窗口。

什么是快速库存？

一个产品网格，每个方块上都有 + 和 −：点一下加一或减一。适合在柜台使用，也适合没有条码的商品（无条形码 筛选只显示这些商品）。点击方块可打开完整的库存窗口。

点了 + 或 − 之后，该方块上的价格会被一个撤销箭头替换几秒钟。列表滚动时的点击会被忽略，避免误改库存。

清点后如何设置准确数量？

使用盘点。你只需输入清点出的数量，应用会自动算出差额并记录为一次调整，不用自己做减法。

为什么应用拒绝出库，或者说这里的数量不够？

库存不能低于零。如果一个产品存放在多个地方，出库会从你选择的地方（或默认位置）扣除。那里不够时，提示会告诉你其余的库存在哪里，例如：“此处仅有 3 个。库存分布：A 店 5，货车 2”。请在 出库来源 中选择那个地方，或者先移动库存。

我输错了数量，怎么改？

请看更正或撤销一条变动。

位置与调拨

把库存放在多个地方 — 仓库、门店、货车、货架 — 并在它们之间移动。

如何把库存从一个位置调拨到另一个位置？

1. 创建位置（只需一次）：⋮ → 位置 → +，给每个位置起一个名称和简短代码（例如 主仓库、WH-1），然后保存。

2. 移动库存：

  1. 打开产品。库存位置 卡片会列出存放该产品的每一个地方。
  2. 点击库存当前所在位置的那一行，然后点击 移动。
  3. 在 到 中选择目的地并输入数量（会显示可用数量）。
  4. 确认。只有这部分数量会被移动，其余的留在原处。

也可以从位置操作：⋮ → 位置，点击该位置，在存放于此的任意产品旁使用 移动。

每次调拨都会在 交易 中显示为 调拨（“仓库 → A 店”），并出现在 调拨日志 报表中。弄错了？在交易中打开它，点击 撤销。

要移动产品的全部库存，也可以编辑产品并修改其 位置。如果它的库存全部在一个地方，库存会随之移动。

我看不到“库存位置”卡片或移动按钮。
  • 先创建至少一个位置。只有存在可以移动到的地方时，这张卡片才会出现。
  • 更新应用。移动产品的部分库存是在 1.79 版加入的；更早的版本只能修改整个产品的位置。
我的库存显示为“无库位”，如何放到某个位置？

在创建位置之前添加的库存（或其位置已被删除的库存）记在 无库位 下。像其他库存一样移动它：打开产品，在 库存位置 中点击 无库位 那一行，然后点击 移动 并选择位置。

什么是默认位置？

当你不做选择时，新库存进入、出库扣除的地方。在 位置 中编辑一个位置，打开 设为默认。只存放在一个地方的产品总是使用那个地方。

如何选择出库或销售从哪里扣？

当产品存放在多个地方或批次时，库存窗口会显示 出库来源。保持 自动（先过期先出），或选择确切的地方或批次。在销售中，点击 出库位置：默认位置 为这次销售选择位置。

产品分散存放时，快速库存的 + 和 − 会询问从哪里。要始终使用默认位置，关闭 设置 → 库存变动 → 库存分散时询问位置。

可以把库存标记为损坏、预留或隔离吗？

可以。按上面的方法移动它，并更改 状态（良好、已损坏、已预留、隔离），代替或同时更改位置。它仍然计入库存，但只有状态良好的库存才会被销售或自动出库。

删除一个位置后，库存会怎样？

不会丢失任何东西。它的库存会转到 无库位，相关产品也不再属于该位置。从回收站恢复该位置会重新关联产品，但库存仍留在“无库位”下，直到你把它移回去。

批次、有效期和序列号

适用于食品、药品、化妆品、电子产品……任何会过期或有序列号的商品。

如何记录批次、有效期或序列号？

入库时，在入库窗口中展开 批次、有效期、序列号 部分。按需填写：批次号、有效期至、供应商、单位成本、序列号。普通库存保持收起即可。

序列号每行一个、每件一个：行数必须等于数量。如果你在大多数到货时都填写这些字段，这部分会自动展开。

出库时先用哪个批次？

默认先用最早过期的，其次是最早到货的。你也可以随时在 出库来源 中指定批次。

如何查看快要过期的商品？

有临期商品时，仪表盘会显示 即将过期 卡片（已过期或 30 天内过期）。有效期 报表按剩余天数列出每个批次，最近的排在最前。

库存价值是怎么计算的？

每次到货都会保留其入库成本。在 设置 → 库存变动 → 库存估值方式 中选择：现有库存的平均成本、最近一次入库成本或商品的成本价。该设置用于库存估值报表和产品页上的库存价值。

条码扫描

用手机摄像头查找产品、登记库存和查价格。

如何扫描条码？

打开 扫描，把摄像头对准条码。如果有产品使用这个条码，会打开它的库存窗口：选择 入库 或 出库 并输入数量。光线暗时可以用手电筒按钮。

提示“未知条码”。

还没有产品使用这个条码。点击 以此条码添加产品 新建一个已填好条码的产品，或点击 在商品中搜索此代码 把它关联到已有产品。

如果扫描到的代码与某个产品的 SKU 相同，应用会显示“通过 SKU 找到 — 该商品尚未保存条形码。”，并提议把它保存为该产品的条码。

可以连续扫描很多商品（一批到货）吗？

可以：在扫描界面打开 批量开。每扫一次就把产品加入列表，再扫同一产品就加一。然后把整个列表一次性保存为入库或出库。未知代码会单独列出并跳过。

如何扫码查价格？

在扫描界面打开 查价。每次扫码都会用大字显示售价，下面是成本和利润、库存价值、各批次成本和近期销售。摄像头会持续扫描，可以一件接一件地查。顾客能看到屏幕时，点眼睛图标可隐藏成本和利润。

支持哪些条码？扫得慢或读错码怎么办？

EAN-13、EAN-8、UPC-A、UPC-E、Code-128、Code-39、Code-93、二维码和 Data Matrix。在 设置 → 条码格式 中关闭你从不使用的格式：格式越少，扫得越快、误读越少。提示音和振动在 设置 → 扫描反馈 中设置。

扫描界面说需要摄像头权限。

点击 允许相机。如果之前拒绝过，Android 不会再询问：点击 打开应用设置，在“权限”中允许摄像头。摄像头只在扫描界面（或拍照）打开时使用，图像在手机上处理。

可以使用扫码枪（USB / 蓝牙 / PDA 手持终端）吗？

可以，通过远程访问：在该设备的浏览器中打开应用，使用扫描页面或手持终端视图，它会读取扫码枪输入的代码。请看手持终端。

盘点

清点货架上的实际数量，一步更正应用中的数据。

如何盘点？
  1. 从 ⋮ 菜单打开 盘点。
  2. 在 盘点位置 中选择你正在清点的地方（或所有位置）。
  3. 对每个产品，上下滑动计数器、点击它输入准确数量，或扫码逐件累加。留空的产品会被跳过。
  4. 点击 应用盘点。只有你改动过的产品会被调整，每个差额都记录为一次调整。

分多个批次存放的产品会按批次逐一清点。清点期间发生的销售会被考虑在内，不会被重复计算。

离开界面之前请点击应用盘点。未应用的清点结果不会保留。
应用能提醒我盘点吗？

可以：设置 → 盘点提醒 → 提醒我进行盘点。选择每天、每周（某个星期几）或每月（某一天），以及时间。

销售与单据

一个简单的收银台：销售、扣减库存，并打印或分享单据。

如何销售并开单？
  1. 从 ⋮ 菜单打开 销售。
  2. 点击产品或扫描条码，把它们加入购物车。在购物车里可以修改每行的数量、价格和折扣。
  3. 点击 结账。可选择填写顾客姓名和电话、付款方式（现金、银行卡、银行转账、移动支付、赊账）、折扣、税和实收金额。找零会自动计算。
  4. 点击 完成销售，然后打印或分享单据。

库存会同时扣减，这笔销售会出现在交易和销售与毛利报表中。如果有商品库存不足，则什么都不会卖出，应用会告诉你是哪一件。

以前的单据在哪里？可以重新打印吗？

在销售界面点击顶部的 账单。可按单号、顾客或电话搜索，按今天、7 天、30 天或全部筛选，打开单据即可再次打印或分享。扫描单据上印的条码也能打开它。

如何取消一笔销售或处理退货？

在 账单 中打开单据，点击 作废账单。所有商品都会回到库存，单据会保留并标记为“作废”，这样它的编号仍然可以查到。作废针对整张单据：部分退货时，先作废再重新销售，或为退回的商品记录一次入库。

如何修改单据样式（店名、标志、纸张大小）？

在销售界面点击 账单样式。选择一个默认样式：58 毫米收据 或 80 毫米收据 用于热敏小票打印机，半页 (A5) 或 发票 (A4) 用于普通打印机。然后设置店名、地址和联系方式、税号或登记号、标题、页脚文字、税名和税率、编号前缀和下一个单号。预览就是真实的单据。保存销售后立即打印 可以在柜台省掉一步。

如何用热敏 / 蓝牙 / USB 小票打印机打印？

单据通过 Android 的打印对话框打印，所以任何有 Android 打印服务的打印机都可以。从 Google Play 安装打印机的打印服务应用（或通用打印服务），选择 58 毫米或 80 毫米样式，然后在打印对话框中选择打印机。没有打印机时，也可以保存为 PDF 并分享。

单据是正式的税务发票吗？

单据可以显示你的税号或登记号以及税额行，但它没有经过任何国家官方税务或电子发票系统的认证。请确认当地法规的要求。

记录与更正

每一次库存变化都有记录，每一个错误都能撤销。

在哪里查看所有库存变动？

交易 列出每一条变动：入库、出库、调整和调拨，以及操作人、原因和变动前后的库存。可按日期范围和类型筛选，或按产品、SKU、原因搜索。每个产品的页面也会显示它自己的变动记录。

如何更正或撤销一条变动？
  • 完全撤销：在 交易（或产品的变动记录）中点击它，选择 撤销。库存恢复原状，这条变动进入回收站。
  • 原地更正：在产品的变动记录中点击该变动，选择 编辑，修改数量、原因、批次、供应商、有效期或成本。它保留原来的日期，并标记为已编辑。
  • 刚在快速库存里操作？点击方块上的撤销箭头。

如果撤销或编辑会让库存低于零（例如你想撤销的那批到货已经卖掉了），操作会被拒绝。

报表、导出与标签

把数据导出为 CSV 或 PDF，以及打印标签。

如何导出报表（Excel / PDF）？
  1. 打开 报表。
  2. 设置范围：库存类报表按类别，变动类报表按日期范围。每份报表都会显示将包含多少行。
  3. 点击报表，然后选择 CSV（可用 Excel、Google 表格、WPS、LibreOffice 打开）或 PDF。
库存出入库
现有库存 · 低库存 · 缺货 · 库存过剩 · 库存估值 · 产品目录 · 按库位统计库存 · 有效期 库存变动 · 入库 · 出库 · 调整审计 · 调拨日志 · 成本价变动 · 销售与毛利
可以在 PDF 报表上放公司标志和名称吗？

可以。在 报表 中点击顶部的 报表版式（也可在 设置 → PDF 报表 中进入）。可设置纸张大小、方向、页边距、标志、公司名称、字体、表格样式、页脚、页码和强调色，或从四个预设之一开始。预览就是真实的 PDF。

如何打印条码标签或价格标签？
  1. 从 ⋮ 菜单打开 标签。
  2. 点击 预设 添加现成的样式（零售价签、货架边标签、小号条码贴纸、热敏卷筒标签、二维码资产标签……），或用 新建标签 自己设计：尺寸、排版、字体、字段和条码类型。
  3. 点击 打印，选择产品并打印。所有标签会生成一个 PDF。

只打印一个产品时，打开它并点击顶部的 打印标签。要用实体打印机打印，需要从 Google Play 安装打印服务（打印机厂商的应用或 Mopria）；否则保存为 PDF。

从表格导入

从 CSV 文件导入产品、类别、供应商或位置。

如何从 Excel 或 Google 表格导入产品？
  1. 在 Excel 或 Google 表格中，把工作表另存为或下载为 CSV。应用读取的是 CSV 文件，不是 .xlsx。
  2. 从 ⋮ 菜单打开 导入，选择要导入的内容（商品、类别、供应商或库位）。
  3. 点击 选择 CSV 文件。不确定需要哪些列？点击 保存 CSV 模板，填好后选择该文件。
  4. 检查预览。每一行都标为 新增 或 更新，警告和被拒绝的行都有说明。选择选项后点击 导入。

在你确认之前，不会写入任何数据。

文件需要哪些列？

导入产品时，只有 sku 和 name 是必需的。还可以包含：description、category、location、quantity、unit、min、max、cost、price、barcode、supplier、image。第一行必须是列名。许多常见写法都能识别（qty、stock、unit price……，以及应用自己导出的中文表头），导入界面会列出所有可接受的名称。示例：

sku,name,category,quantity,unit,cost,price,barcode
A-100,螺丝,五金,25,个,4.50,9.99,4006381333931

逗号、分号或制表符分隔、小数逗号、货币符号以及大多数日期格式都能处理。需要推测某个值时，预览会说明是如何读取的。

导入会覆盖我已有的产品吗？

只有你需要时才会。产品按 SKU 匹配。打开 更新已存在的记录 后，匹配到的产品会获得文件中的值，并且只更新文件里有的列。只有 sku,name,quantity 的文件不会清空价格或类别。关闭它则只添加新产品。

如果某个产品的库存分散在多个位置或批次中，文件无法说明新数量属于哪里，请在该产品的页面上修改它的库存。

如何把整个产品清单导到 Excel？

将 产品目录 或 现有库存 报表导出为 CSV（见报表）。这个 CSV 也可以再导回应用。

备份、恢复与换手机

你的数据存放在手机上。手机丢失或重置时，保存在别处的备份才能救回数据。

卸载应用或清除其存储会删除你的全部数据。做这两件事之前，请先设置好备份。
如何备份数据？
  1. 从 ⋮ 菜单打开 备份。
  2. 点击 添加目标位置，选择备份保存到哪里：本机文件夹（内部存储、SD 卡、U 盘，或云盘应用同步的文件夹）、FTP 服务器 或 共享文件夹（SMB）（NAS 或 Windows 电脑上的共享文件夹）。
  3. 如果是服务器，输入地址和登录信息，然后点击 测试连接。它会确认确实能在那里写入文件。
  4. 点击 立即备份，并打开 自动备份，大约每天自动保存一份。

每次备份都会写入你所有的目标位置。如果其中一个不再可用，你会收到通知，仪表盘上也会显示横幅，直到问题解决。

如何恢复备份？

在 备份 中找到备份，点击 恢复。在任何数据改变之前，你可以选择恢复哪些数据并查看备份内容。恢复会用备份中的数据替换当前数据。

“此备份由更新版本的应用创建。请先更新应用，再恢复。”表示需要先从 Google Play 安装最新版本。

如何把数据转移到新手机？
  1. 在旧手机上，把备份保存到新手机能访问的地方：FTP/SMB 服务器、与云同步的文件夹，或你自己复制过去的文件。
  2. 在新手机上安装 Stock Management。在欢迎界面选择 恢复备份，然后选择 从文件、从服务器 或 从文件夹。

为了安全，服务器密码不会保存在备份里。请在新手机上重新输入。

两部手机可以共用同一份库存吗？

应用没有在线账号，所以两部手机之间不会同步。要让多人处理同一份库存，请把数据保留在一部手机上，其他人通过同一 Wi-Fi 下的浏览器使用远程访问。在另一部手机上恢复的备份只是一个副本：一边的修改不会出现在另一边。

在电脑、平板或手持终端上使用（远程访问）

同一 Wi-Fi 下的其他设备可以在浏览器中打开你的库存，每个人有自己的登录和权限。

如何在电脑上打开应用？
  1. 在手机上，从 ⋮ 菜单打开 远程访问。如果手机设置了锁屏，请验证。
  2. 点击 启动服务器。屏幕会显示一个地址（如 http://192.168.1.24:8080）和一个二维码。
  3. 点击 添加成员，创建登录信息：姓名、用户名和密码。
  4. 在该用户上点击 选择，勾选他可以使用的界面和操作（或选一个预设：仅查看、盘点员、查价机、全部）。在你勾选之前，什么都不允许。
  5. 在电脑的浏览器（Chrome、Edge、Firefox、Safari）中输入该地址并登录。
  6. 用完后，点击 停止服务器。

在浏览器中做的每一项修改都会以该用户的名字记录到手机上。服务器永远不会自己启动。

浏览器打不开这个地址。
  • 两台设备必须连接同一个 Wi-Fi（或电脑连接手机的热点）。移动数据不行。
  • 访客或公共 Wi-Fi 通常不允许设备互相访问。请使用你的主网络或手机热点。
  • 完整输入地址，包括 http:// 和端口（:8080）。
  • 确认服务器仍在运行。从最近任务中划掉应用会停止服务器，切换网络也会。
  • 名称形式的地址（以 .local 结尾）只有在路由器支持时才可用。请改用数字地址。
  • 允许应用的通知。服务器运行时，它的通知里有停止按钮。
在浏览器里能做什么？

你允许的内容：仪表盘、产品（查看、添加、编辑）、扫描、快速库存、盘点、记录、报表（CSV/PDF）、分类、供应商、位置、在位置之间移动库存、打印标签和查价。备份、导入、回收站、标签设计、设置、销售以及远程访问本身只能在手机上使用。在浏览器中无法删除任何东西。

每个浏览器都可以在 显示 中选择自己的浅色或深色模式、主题、文字大小和列表视图。

使用手持终端（PDA）或 USB 扫码枪

在该设备的浏览器中打开地址，用有扫描权限的账号登录。点击顶部的手持终端图标，选择 收货 或 出库，然后扫码。每个代码都会加入列表（再扫一次加一），一个按钮即可保存全部。打开 随处读取扫描枪按键，屏幕键盘就不会挡住。

如果 Wi-Fi 断开，未保存的列表会保留在设备上，恢复后再保存即可。浏览器无法使用设备摄像头扫码（需要安全连接），请使用扫码枪或手动输入代码。

顾客可以自己在屏幕上查价格吗？

可以。用 查价机 预设创建一个登录，在柜台带扫码枪的电脑或平板上打开查价，然后选择 查价屏幕。它会显示你的标志和公司名称（来自报表设计），并提供全屏按钮。显示哪些内容、何时清屏在 设置 → 查价屏幕 中设置。

远程访问安全吗？
  • 它只在私有网络（家庭或办公室 Wi-Fi、手机热点）中工作，从不暴露在互联网上。
  • 每个人都有自己的密码，只能看到你勾选的内容。你可以看到谁已连接、断开他们、停用账号或重置密码，并查看最近的活动。
  • 连接没有加密：请在可信网络中使用，不要在公共 Wi-Fi 上使用。
  • 如果手机没有设置锁屏，任何拿到手机的人都能打开远程访问。给手机设置锁屏即可保护它。

通知

低库存提醒、盘点提醒和备份警告。

低库存提醒怎么工作？可以选择时间吗？

应用每天发送一次低于最低库存的产品汇总。在 设置 → 通知 → 低库存提醒时间 中选择时间。它会在该时间前后送达，因为 Android 可能为了省电推迟几分钟。

我收不到任何通知。
  • 确认 设置 → 通知 → 启用通知 已打开。
  • 允许应用的通知：点击仪表盘卡片上的 开启提醒，或进入 Android 设置 → 应用 → Stock Management → 通知。
  • 每种通知（低库存提醒、盘点提醒、备份问题、远程访问）都可以在 Android 的应用通知设置中单独开关。
  • 有些手机（小米、华为、荣耀、OPPO、vivo、三星……）会为省电关闭后台应用。请允许本应用在后台运行，或把它的电池使用设为“无限制”。

回收站

在你清空之前，删除的东西都不会真正消失。

如何找回删除的内容？

从 ⋮ 菜单打开 回收站。被删除的产品、类别、供应商、位置、标签以及被撤销的变动都在这里。点击 恢复：应用会先准确告诉你将发生什么。恢复只会添加，绝不会覆盖你现有的任何内容（重复的 SKU 或名称会得到一个新的，例如 A-100-2）。

永久删除 删除一条；清空 清空整个回收站。两者都不影响你当前的数据。

请在 Google Play 更新 Stock Management。最近的更新加入了在位置之间移动库存、批次和序列号、销售和单据、查价格等功能。更新时你的数据会保留。
